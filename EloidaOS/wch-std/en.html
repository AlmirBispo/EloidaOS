Firmware Base EloidaOS

Documentação de Referência — CH32V307 (portável para CH32V208)
Versão V7.0.0 · Autor: Almir Bispo · 2026
Nota de compatibilidade (CH32V208): Este firmware foi escrito para o CH32V307, que possui PHY Ethernet 10M integrado (sem PHY externo). As chamadas de API de rede (ETH_LibInit, WCHNET_DHCPStart, WCHNET_SocketSend, etc.) são compatíveis com o CH32V208, pois ambos usam a mesma netlib distribuída com o MounRiver Studio e também possuem PHY 10M interno. Para portar, basta ajustar o ambiente de compilação: criar um projeto CH32V208 na IDE, substituir o eth_driver.c, o startup e o header ch32v30x.h pela versão ch32v20x, e revisar a configuração de clock. A lógica do main.c (kernel cooperativo, provisionamento, parsing de strings, SPI Flash, RTC, UART4) é reaproveitável.

1. Visão geral

O EloidaOS Base Firmware é um kernel cooperativo voltado para conectividade Ethernet robusta (DHCP, DNS, cliente HTTP) e armazenamento em Flash SPI externa (W25Qxx). Inclui sistema de provisionamento, ponte UART4 para o módulo WiFi HLK-RM08K e gerenciamento de RTC. A lógica de negócio é intencionalmente deixada em branco nas tarefas, servindo de base limpa para a aplicação.

3.9 Tarefas

TarefaComportamento padrão
task0..task4, task6..task13Vazias — placeholders para a lógica de negócio.
task5Chama RTC_Get() para atualizar o calendário.
task_redeBackoff de rede: aguarda DHCP, verifica conexão e, a cada 5 s, tenta WCHNET_CreateTcpSocket até MAX_RETRY_ATTEMPTS.
task14Provisionamento via HTTP: envia token, parseia <device_token_id> e <bit0..4> e, se o token bater, chama gravar_provisao(). Limite de 10 tentativas (PROV_POSSIBILITY).

4. Fluxo do main()

  1. NVIC (grupo 2), SystemCoreClockUpdate, Delay_Init, printf em 115200, espera de 3 s.
  2. TIM2_Init, SPI_Flash_Init, banner e carregar_provisao().
  3. Verificação da versão da biblioteca WCHNET; leitura do MAC; set_hostname e WCHNET_DHCPSetHostname.
  4. ETH_LibInit, WCHNET_DHCPStart com o callback do firmware.
  5. uart_wifi_data_init, RTC_Init.
  6. Loop principal:
    • WCHNET_MainTask();
    • para cada índice i: process(PRIME_NUMS[i], i) → run(i) → destroy(i);
    • WCHNET_QueryGlobalInt / WCHNET_HandleGlobalInt;
    • Delay_Us(10).

Reference Documentation — CH32V307 (portable to CH32V208)
Version V7.0.0 · Author: Almir Bispo · 2026
CH32V208 compatibility note: This firmware targets the CH32V307, which has an integrated 10M Ethernet PHY (no external PHY required). The network API calls (ETH_LibInit, WCHNET_DHCPStart, WCHNET_SocketSend, etc.) are compatible with the CH32V208, since both use the same netlib shipped with MounRiver Studio and both have an internal 10M PHY. Porting only requires adjusting the build environment: create a CH32V208 project in the IDE, replace eth_driver.c, the startup file and ch32v30x.h with the ch32v20x versions, and review the clock configuration. The main.c logic (cooperative kernel, provisioning, string parsing, SPI Flash, RTC, UART4) is reusable as-is.

1. Overview

The EloidaOS Base Firmware is a cooperative kernel focused on robust Ethernet connectivity (DHCP, DNS, HTTP client) and external SPI Flash storage (W25Qxx). It includes a provisioning system, a UART4 bridge to the HLK-RM08K WiFi module, and RTC management. Business logic is intentionally left empty inside the tasks, providing a clean foundation for applications.

3.7 Cooperative kernel

FunctionDescription

3.8 Provisioning

FunctionDescription

reset_provisao()Erases the provisioning sector and clears the context.

3.9 Tasks

TaskDefault behavior
task0..task4, task6..task13Empty — business-logic placeholders.
task5Calls RTC_Get() to refresh the calendar.
task_redeNetwork backoff: waits for DHCP, checks the connection, and every 5 s tries WCHNET_CreateTcpSocket up to MAX_RETRY_ATTEMPTS.
task14HTTP provisioning: sends the token, parses <device_token_id> and <bit0..4>, and calls gravar_provisao() when the token matches. Capped at 10 attempts (PROV_POSSIBILITY).

4. main() flow

  1. NVIC (group 2), SystemCoreClockUpdate, Delay_Init, printf at 115200, 3 s delay.
  2. TIM2_Init, SPI_Flash_Init, banner, and carregar_provisao().
  3. WCHNET library version check; MAC read; set_hostname and WCHNET_DHCPSetHostname.
  4. ETH_LibInit, WCHNET_DHCPStart with the firmware callback.
  5. uart_wifi_data_init, RTC_Init.
  6. Main loop:
    • WCHNET_MainTask();
    • for each index i: process(PRIME_NUMS[i], i) → run(i) → destroy(i);
    • WCHNET_QueryGlobalInt / WCHNET_HandleGlobalInt;
    • Delay_Us(10).
